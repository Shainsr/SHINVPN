# تغییرات SHIN VPN 1.1.0

- تفکیک کد Dart به بخش‌های سطح‌بالا در `lib/src/`.
- هماهنگ‌سازی نسخه برنامه روی `1.1.0+49`.
- افزودن Drawable مخصوص آیکون اعلان.
- حذف پذیرش خودکار گواهی‌های TLS نامعتبر هنگام دریافت Subscription.
- حفظ HTTPS در تست تونل و استفاده از یک HttpClient برای دو درخواست ترتیبی.
- بازگشت Adaptive Ping به‌صورت batch scheduler با بازه ۲ تا ۸ worker و شروع از ۴.
- تغییر Auto-Failover به پایش سلامت و پیشنهاد تعویض سرور با تأیید صریح کاربر.
- همسان‌سازی Gradle Wrapper و تنظیمات CI.

توجه: ساخت APK و اجرای `flutter analyze` در محیط آماده‌سازی ممکن نبود؛ پیش از انتشار باید CI سبز و تست دستگاه واقعی انجام شود.
